Стенд состоит из 4 виртуальных машин, поднятых через Vagrant.

Для PostgreSQL сделан отказоустойчивый кластер: Patroni + etcd в качестве DCS, между двумя нодами настроена репликация. HAProxy смотрит на статус нод через Patroni и всегда пускает клиентов на текущий Primary - если он меняется, адрес подключения (порт 5432) остаётся тем же. Кроме этого создана обычная БД с пользователем, отдельный  пользователь для мониторинга, и включена статистика  (pg_stat_statements). 

Дальше k3s с ingress-nginx  и самоподписанным сертификатом для HTTPS. В кластере Prometheus и Grafana, данные не теряются при пересоздании подов. Метрики с самих VM собирает node_exporter, метрики PostgreSQL - postgres_exporter, подключение к базе у него идёт через Kubernetes Secret. В Grafana подключён Prometheus и настроены дашборды.
